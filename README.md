# fluter cash

A mobile-first savings and rewards app interface prototype with a deep navy theme and electric-purple/pink accents.

## Included screens
- Splash screen
- Sign in and sign up
- Wallet dashboard and quick actions
- Savings goal preview
- Rewards and bonus claim interaction
- Transaction activity and filters
- Profile and support

## Run locally
Open `index.html` in a modern browser.

## Demo notice
This repository contains a front-end demonstration only. Authentication, bank connections, payments, wallet balances, and transaction records are simulated in the browser. Do not use it to store real financial or personal information.

## Deployment
The GitHub Actions workflow in `.github/workflows/deploy.yml` publishes the static site to GitHub Pages on pushes to `main`.
